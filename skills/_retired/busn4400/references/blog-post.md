# Blog Post — Sub-Process

## What It Is
An 800-1200 word blog post for the BUSN 4400 class WordPress blog. Audience is peers. Graded on effort, creativity, and effective use of generative AI.

## Specs
- Length: 800-1200 words
- Tone: analytical and moderately casual — sounds like Jacob, not like a corporate blog
- Structure: clear sections with readable headers (not bold formal titles)
- Must include: 4-7 hyperlinked sources embedded naturally in text, at least one class example reference, screenshot placement markers [INSERT SCREENSHOT HERE]
- Must include: a separate "How I Used Generative AI" paragraph at the end (not part of word count)
- Must not: sound AI-generated, use filler phrases, pad with unnecessary content

## Jacob's Voice Reference
Analytical structure, casual articulation, no fluff, gets to the point. Short prose and bullets where bullets genuinely help. Confident without being stiff.

## Process
1. Confirm the blog topic and angle
2. Confirm which AI tool was used (must differ from prior posts)
3. Draft in case-study or experiment format depending on topic type
4. Embed source hyperlinks naturally — never as a reference list at the end
5. Add screenshot markers where visuals would logically appear
6. Write the GenAI reflection paragraph separately
7. Run avoid-ai-writing on the completed draft before returning output

## Output
Full blog post text ready to paste into WordPress, followed by the separate GenAI paragraph. Copy-ready.
